# 小山少年野球団オレンジ 記録システム

3年生以下チーム「オレンジ」の成績記録・表彰・懇親会運営を支えるシステムです。
父母が試合ごとの成績を入力すると、個人の成長がグラフとスタンプで見られるようになります。

## 仕組み

- **フロント**：GitHub Pages（素のHTML/CSS/JS）
- **中間**：Google Apps Script（GAS）
- **データ**：Googleスプレッドシート

サーバー不要・無料枠で運用しています。
2026年8月に、スプレッドシートとGASをチーム用Googleアカウントへ移行しました。

### リンク集の仕組み

リンク集に表示される内容は、**すべてスプレッドシートの `links` シート**から読み込んでいます。
HTMLにはリンク先が一切書かれていません。

- リンクの追加・修正は、シートに行を足すだけ。**プログラムの修正は不要**です
- `category` 列の文字が、そのままページの見出しになります
- 消したいときは行を削除せず、`visible` を `FALSE` にしてください（あとで戻せます）
- `locked` が `TRUE` の行は、ページから編集・削除できません

### 幹事用リンク

トップページの「幹事用」ボタンからパスワードを入れると表示されます。
パスワードは `linkscfg` シートに保管されており、**幹事ページ内から変更できます**。

幹事用のリンクはHTMLに一切書かれておらず、パスワードが通ったときに初めて読み込まれます。
（このリポジトリはPublicのため）

## 幹事の方へ

- 運用手順・年度替わりの作業は、**チーム用Googleドライブの引き継ぎフォルダ**を参照してください。
- **GASを修正したら**「デプロイを管理 → 既存を新バージョンで再デプロイ」。
  「新しいデプロイ」を押すとURLが変わり、全ページが動かなくなります。
- **シート名**は半角小文字・前後スペースなし。変更しないこと。
- ファイル更新は**1回のコミットにまとめて**アップロードしてください（分けるとPages公開が失敗しやすい）。
- 公開が失敗したときは「Actions」タブ → 失敗したrun → 「Re-run jobs」で再実行。
- **名簿から選手を消さないこと。** `roster` から削除すると、その子の過去成績が表示されなくなります
  （データ自体は残っています）。卒団後もそのままにしてください。

### バックアップ

スプレッドシートは**週1回、自動でバックアップ**されています。
保存先はチーム用Googleドライブの `backup` フォルダ。直近10本を保持します。

誤って行を消してしまったときは、ここから前週の状態に戻せます。

## 素材・アカウント情報

- 写真・動画・音などの素材は、チーム用Googleドライブに保管しています。
- 各アカウントのIDとパスワードは、GitHubには置かず**ドライブで管理**しています。
- **チーム用Googleアカウントでログインすれば、資料・データ・システムのすべてにアクセスできます。**
  個別の招待や権限設定は不要です。

### 引き継ぎ時に渡すもの

| 何を | 渡し方 |
|---|---|
| チーム用Googleアカウントのメールアドレスとパスワード | 対面で口頭、または紙 |
| 幹事ページのパスワード | 口頭・LINE可。**交代後に新幹事が変更すること** |
