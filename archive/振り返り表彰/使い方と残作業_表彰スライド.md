## 2. 当日の使い方

### 進行の流れ（1人ずつ）
**賞名が表示 → クリック（ドラムロール🥁）→ 受賞者名がバーン＋拍手 → お菓子を渡す → クリック → その子のインタビュー画面（🎤投げ試合への意気込みをひとこと）→ クリック → 次の子の賞へ**

スライド順：表紙 → チーム振り返り → 【賞→インタビュー】×全員 → はじめての記録①② → **礼（監督・コーチへ）→ 小林コーチのひとこと → 前川監督のひとこと** → しめ

**セレモニー3枚（ver006〜）**：はじめての記録のあと、①みんなで礼「ありがとうございました！」②小林コーチ・③前川監督から投げ試合にむけてひとこと。名前や文言を変えたいときはHTML内の `CEREMONY` 定数（DATAブロックのすぐ下）を直す。**データ取込で貼り替えても消えない場所**にある。

**チーム振り返り（チームのきせき）はクリックで1枚ずつ発表**（ver005〜）：
最初はタイトルだけ → クリック→せいせき → クリック→みんなの通算ヒット → クリック→チーム総得点 →（勢いがあれば）クリック→いまの勢い → **クリック→「みんなすごい！」（紙吹雪＋歓声）** → 次のクリックで「今から 個人表彰！」の導入スライド → 賞へ。←で1段ずつ戻せる。

### 操作キー
| 操作 | キー |
|---|---|
| 進む | クリック / → / Space / Enter / PageDown（プレゼンリモコン対応） |
| 戻る | ← / PageUp（賞スライドは発表前の状態に巻き戻る＝言い直し用） |
| 最初へ / 最後へ | Home / End |
| **全画面** | **F** |
| **音ON/OFF（効果音＋BGM全部）** | **M**（左下に表示） |
| **BGMだけON/OFF** | **B**（左下に🎵表示。話が長くなる場面などで） |
| データ取込画面（幹事用） | D（当日は使わない） |

- ドラムロール中にもう一度クリック＝すぐ発表にスキップ（テンポ調整）
- 右下に「n / 総数」の進捗表示あり

## 3. データ取込（締切後に1回やる）

1. ネットにつながるPCで `presentation_1b_sticker.html` を開く
2. **Dキー** → 取込画面（GASのURLは自動入力済み・年度は空欄で今年度）
3. **「取得して生成」** → 10秒ほどで結果が出る
   - ⚠「まだ賞のない子」が表示されたら → 集計システムで手動賞を入れてから取り込み直す
   - 📷「写真ファイル名の対応（01.jpg＝○○…）」も表示される → 写真準備に使う
4. 「生成結果をコピー」
5. HTMLをメモ帳等で開き、`/* ==== DATA START ==== */`〜`/* ==== DATA END ==== */` を**丸ごと貼り替えて保存**
6. 以降は**オフラインで動く**（賞の計算は既存の表彰画面と同一ロジック・検証済み）

※ 焼き込み後にコメント追加・表記修正をしたいときは、DATAブロック内の文字を直接編集すればそのまま画面に反映される。

## 4. 音と写真のルール

### sounds/（固定名MP3・同名で上書きすれば差し替え可）
| ファイル | 鳴る場面 |
|---|---|
| drumroll.mp3 | 受賞者発表前のタメ |
| fanfare.mp3 | 名前がバーンと出る瞬間 |
| applause.mp3 | 拍手（fanfareと同時） |
| **bgm.mp3** | **会中のBGM（ループ再生・ver004で追加）** |
| **cheer.mp3** | **チームのきせき「みんなすごい！」の歓声（ver007で追加・配置済み）** |

- 効果音は**配置済み**（`sounds/素材/` に差し替え候補あり）。無い/読めない場合は内蔵の合成音が自動で鳴る＝**音が出ないことはない**
- **BGMは bgm.mp3 を置いたときだけ流れる**（未配置なら左下に案内表示・エラーにはならない）
  - 最初のクリック操作から流れ始め、**ドラムロール〜発表の間は自動で音量が下がる**（効果音を聞かせるため）
  - 音量調整：HTML内の `BGM_VOLUME`（ふだん・既定0.25）／`BGM_DUCK`（発表中・既定0.07）の数字を変える

### photos/（名簿順の番号2桁.jpg）
- 01.jpg＝名簿の1人目、02.jpg＝2人目…（対応表は取込結果に表示）
- インタビュー画面は**必ず写真枠が入る**レイアウト。未配置の子は😊プレースホルダー表示 → **本番までに全員分を置く**
- 縦長（3:4くらい）がきれい。他の縦横比も自動トリミング
- いまの01.jpg/03.jpgは動作確認用の仮ファイル（上書きする）
