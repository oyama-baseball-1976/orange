## 2. 使い方

### 再生のしかた
1. `orange_movie.html` をブラウザで開く（**photosフォルダと同じ場所に置いたまま**開くこと）
2. 起動画面に「推定の長さ」「写真の検出数」が表示される
   - ⚠ 写真の検出が0だらけなら、photosフォルダが同じ場所に無いサイン
3. **クリック → 3秒カウントダウン → 最後まで完全自動**（操作不要）
4. 最後のシーンで静止する
5. やり直し：**Rキー**（またはクリック2回）でスタート画面に戻る

### 編集ポイント（すべてHTMLコード上部・メモ帳でOK）

**① MEMBERS＝加入順リスト**（行の並び順＝登場順。noは背番号）
```js
const MEMBERS = [
  { no: 7,  name: "○○ ○○" },   // ← 一番最初に加入した子
  { no: 12, name: "○○ ○○" },   // ← 2番目
  ...
];
```

**② CONFIG＝秒数**（例：選手1人を4秒にする → member の sec を 4 に）
```js
member:   { sec: 3.5, fade: 0.5 },   /* 第1章：選手1人あたり */
practice: { secPerPhoto: 5, ... },   /* 第2章：写真1枚あたり */
```

**③ TEXTS＝画面に出る文言**（タイトル・章名・「完成！」・しめの言葉など）

### 写真の置き方（ver009/photos/）

| フォルダ | ファイル名 | 用途 |
|---|---|---|
| members/ | **背番号2桁.jpg**（例：07.jpg。コーチは21〜25） | 第1章の選手紹介。縦長（3:4くらい）がきれい |
| taiken/ | 01.jpg, 02.jpg…（連番・枚数自由） | 第2章 冬：体験会のようす |
| junbi/ dash/ catch/ hoshoku/ shidou/ | 各フォルダに連番 | 第2章 夏：準備運動／ダッシュ／キャッチボール／補食／監督・コーチの指導 |
| fun/ | 連番 | 第2章：肩組み・ポーズなど楽しい写真（挟む位置は台本で変更可） |
| kaikai/ | 連番 | 第3章：開会式の写真 |
| game1/〜game5/ | **01.jpg＝整列・挨拶、02.jpg〜＝プレー写真**（枚数自由） | 第3章：各試合。試合の増減はHTML上部CH3_SCRIPTの3行セット（vs→photos→result）をコピー/削除。**game5＝最終戦 亀城ベースボールA（01=挨拶、02=スコアボードの2枚構成）** |
| team/ | 01.jpg（＋あれば02.jpg） | 01＝第1章しめの集合写真／02＝「つづく」スライドの背景（別の写真にしたいときは下記Dの file 指定） |
| **omake/** | **kaito1〜3.jpg**（かいと：打席→岩田コーチ→守備）／**sayo1〜3.jpg**（さよ：同） | おまけ：新メンバー紹介（大会総括のあと。無い写真の行はスキップ） |
| **ending/** | **kids.jpg**（子どもの集合写真・初試合）／**parents.jpg**（それを撮る親たち） | エンディングの対比演出（どちらか無ければその場面はスキップ） |

- 写真が無い選手は背番号バッジで代替表示。**空のフォルダの場面は自然にスキップ**（枚数の増減自由）
- 練習/大会は**横長写真が画面いっぱい**に表示される（自動トリミング）
- **テロップの文言・秒数・順番・相手名・勝敗（○/●）は、HTML上部の `CH2_SCRIPT`／`CH3_SCRIPT`（台本）を直すだけ**（録り直し前に文言だけ調整できる）
- **写真1枚ずつ違うキャプション**を付けたいときは `{type:"photo", file:"taiken/01.jpg", caption:"…"}` の行を使う（CH2に実例あり）
- いま入っているのは動作確認用の白いサンプル。**本番写真で上書き**する

## 2.5 台本の書き方（コピペして使える例）

台本＝HTML上部の `CH2_SCRIPT`（練習の日々）と `CH3_SCRIPT`（大会）。**行の並び順＝流れる順番**で、行の追加・削除・並び替えは自由。行末のカンマ「,」を忘れないこと（最後の行だけ無しでもOK）。

### A. 写真1枚ずつに違うテロップを付ける（type:"photo"）

```js
{ type:"photo", file:"taiken/01.jpg", caption:"たいけんかいを ひらいたよ！", sec:3.5 },
{ type:"photo", file:"taiken/02.jpg", caption:"きてくれるかな…？ ドキドキ", sec:3.5 },
{ type:"photo", file:"taiken/03.jpg", caption:"いっぱい きてくれた！！", sec:3.5 },
```

- `file` ＝ photos/ から見た場所（フォルダ名/ファイル名）。`caption`＝その1枚だけの一言。`sec`＝表示秒数。
- **指定したファイルが無い行は自動でスキップ**される（エラーで止まらない）。

### B. フォルダの写真をまとめて流す（type:"photos"）との違い・使い分け

```js
{ type:"photos", folder:"dash", caption:"ダッシュ！ はしれ はしれ！", secPerPhoto:3.5 },
```

| | photo（1枚指定） | photos（フォルダ一括） |
|---|---|---|
| キャプション | **1枚ごとに変えられる** | フォルダ内ぜんぶ同じ一言 |
| 写真が増えたとき | **行を1行足す必要がある** | フォルダに入れるだけで自動で流れる |
| 向いている場面 | 1枚ずつ語りたい場面（体験会の流れ等） | 同じ調子で見せる場面（練習風景等） |

- 混ぜて使える。例：最初の1枚だけ `photo` で語り、残りは `photos` に `skipFirst:true` を付けて01.jpgを飛ばして一括で流す：

```js
{ type:"photo",  file:"taiken/01.jpg", caption:"たいけんかいを ひらいたよ！", sec:3.5 },
{ type:"photos", folder:"taiken", skipFirst:true, caption:"いっしょに やきゅう たのしい！", secPerPhoto:3.5 },
```

### C. 集合写真に「写っていない人」を合成する（type:"groupphoto"）

```js
{ type:"groupphoto", file:"team/01.jpg", missing:[3, 7, 12], caption:"みんな そろって さいこう！", sec:8 },
```

- `missing` ＝ 写っていない人の**背番号**をカンマ区切りで列挙（コーチ・監督は写真番号：21=石本・22=小林・23=前川・24=大野・25=岩田）。
- 顔写真は **photos/members/背番号2桁.jpg** を自動で流用（新しく写真を用意する必要なし）。写真が無い番号は背番号バッジ（コーチはコ/監）で表示。
- 顔写真は集合写真の**上部に横一列**で自動整列。人数が増えると自動で少し小さくなる（決め打ちなし）。
- `missing:[]`（空）なら、ただの集合写真として普通に表示される。
- どの章の台本にも書ける。**第1章のしめの集合写真**だけは台本の外なので、HTML上部の
  `const CH1_GROUP_MISSING = [ ];` に背番号を書く（例：`[3, 12]`）。

### D. エンディング（ver007〜：対比写真→つづく→表彰式への導線）

エンディング全体は HTML上部の `ENDING_SCRIPT` で構成される（並び順＝流れる順番）：

```js
const ENDING_SCRIPT=[
  /* 対比写真：子どもの集合写真が全画面→引いて1枚の写真になり、撮っていた親たちが見えてくる */
  { type:"reveal",   front:"ending/kids.jpg", back:"ending/parents.jpg",
    caption:"みんなの えがおを、ずっと そばで", holdSec:3.5, sec:10 },
  { type:"closing",  sec:15 },   /* 「オレンジは これからも つづく」（文言はTEXTSのendingMsg） */
  { type:"telop",    text:"このあと いよいよ\nなげしあいが はじまるよ！", sec:4.5 },
  { type:"highlight",text:"そのまえに…\nみんなの がんばりを ふりかえろう！ 🏆", sec:6 }
];
```

- `reveal` の `holdSec`＝子どもの写真を全画面で見せる秒数、`sec`＝この場面ぜんたいの秒数、`caption`＝親の写真に出る一言（仮文言なので後で書き換える）。
- ver008：子どもの写真は引いたあと**画面の右下**に収まる（親の写真の真ん中を隠さない）。一言テロップは左下に出る。
- 写真は **photos/ending/** に `kids.jpg`（集合写真）と `parents.jpg`（撮っている親たち）を置く。**どちらか無ければこの場面は自動でスキップ**される（止まらない）。

**「つづく」スライドの背景写真を変える方法（ver008〜）**

「オレンジチームの物語はこれからもつづく」の背景は、ふだんは **photos/team/02.jpg**（無ければ01.jpg）が使われる。別の写真にしたいときは2通り：

- **方法1（かんたん）**：photos/team/02.jpg を使いたい写真で上書きする（台本はそのまま）。
- **方法2（台本で指定）**：`closing` の行に `file:` を足す。

```js
  { type:"closing",  sec:15, file:"ending/close.jpg" },   /* ←この写真が背景になる */
```

- `file` は photos/ から見た場所（フォルダ名/ファイル名）。例では photos/ending/ に close.jpg を置く。
- 指定した写真が**無いときは自動で従来どおり**（team/02→01）になる。エラーでは止まらない。

### E. おまけセクション：新メンバー紹介（ver009〜）

大会の総括のあと・エンディングの前に流れる。HTML上部の `OMAKE_SCRIPT` で構成（並び順＝流れる順番）：

```js
const OMAKE_SCRIPT=[
  { type:"divider",  text:"あたらしい なかま！", emoji:"🌟", sec:2.5 },
  { type:"telop",    text:"たいかいの あと…\nあたらしい なかまが ふえたよ！", sec:4.5 },
  /* かいと（打席 → 岩田コーチの指導 → 守備） */
  { type:"photo",    file:"omake/kaito1.jpg", caption:"かいと、はじめての だせき！", sec:3.5 },
  ...
];
```

- 写真は **photos/omake/** に置く（kaito1〜3.jpg＝かいと、sayo1〜3.jpg＝さよ）。**無い写真の行は自動でスキップ**。
- キャプション・秒数は各行で自由に変更。**行を足せば写真が増える**（例：`{ type:"photo", file:"omake/kaito4.jpg", caption:"…", sec:3.5 },`）。
- セクションごと消したいときは、OMAKE_SCRIPT の中身を全部消す（`const OMAKE_SCRIPT=[];` にする）。他の章には影響しない。
- 区切り（divider）の文言・絵文字も1行目で変更できる（第2章の「冬⛄」「夏☀️」と同じ演出）。

## 3. 録画のしかた

1. **ネット接続のあるPC**で開く（Webフォント使用のため。オフラインでも動くが書体が変わる）
2. **16:9のモニター**でブラウザを**全画面（F11）**にする（画面ぴったり・見切れなしになる）
3. 画面録画を開始 → ページをクリック（**3秒カウントダウンが録画開始の余裕**になる）
4. 最後のシーンで静止したら録画停止
5. 失敗したら **R** でスタート画面に戻して録り直し
6. 録画ファイルを動画編集ソフトへ → カウントダウン部分をカット、BGMを付けて完成
